# AudioCompare

`compare.js` is the reusable browser API for the same-room model. It owns the
worker, loads the model and WASM files, keeps raw audio inside the worker
boundary, and only compares serialized per-device packets.

```js
import { AudioCompare } from "./compare.js";

const compare = await AudioCompare.fromObject({
  modelUrl: "/model_output/model.json",
  wasmUrl: "/web-calibration/wasm_parity/wasm/same_room.wasm",
  currentTimestampMs: syncedTimestampAtStartup,
});

const packetA = await compare.prepare(mono16kSamplesA);
const packetB = await compare.prepare(mono16kSamplesB);
const result = await compare.compare(packetA, packetB);

console.log(result.score, result.label, result.windowScores, result.quality);
compare.dispose();
```

`currentTimestampMs` is optional. When supplied, `AudioCompare` samples the
local device clock and stores the offset between it and the synchronized
timestamp. You can update that offset later through the setter:

```js
compare.currentTimestampMs = await getTimestampFromServer();
console.log(compare.currentTimestampMs); // adjusted current timestamp
```

All timestamps generated by `prepare()`, microphone capture, and the default
`getLocalPacket()` lookup use this adjusted clock. Explicit timestamps passed
to `prepare()` and timestamps received by `compare()` or `compareToSelf()` are
treated as already synchronized and are not adjusted.

`prepare()` accepts mono, normalized 16 kHz samples as an `Array`,
`Float32Array`, `Float64Array`, or an `AudioBuffer`. It returns a timestamped
packet object:

```js
{
  timestamp: 1760000000000, // packet-window end, milliseconds since Unix epoch
  buffer: ArrayBuffer,      // compact mel + flux packet
}
```

The packet's `buffer` can be sent through a structured-clone transport such as
a WebRTC data channel. Keep the `timestamp` with it. `compare()` accepts these
objects and also accepts the underlying `ArrayBuffer` for compatibility. It
does not transfer or detach input buffers, so a prepared packet remains
reusable. WAV decoding and resampling are application-specific; the included
demos show how to normalize their inputs before calling `prepare()`.

The default packet format is 8-bit quantized mel data. Override it with
`bitDepth` and `quantize` in the factory options or per-call options:

```js
const unquantized = await compare.prepare(samples, { quantize: false });
```

## Microphone streaming

Call `pipeMicAudio()` from a user interaction, because the browser will ask
for microphone permission. It requests mono, raw-style 16 kHz input, prepares
rolling model-sized packets in the background, and keeps only the most recent
30 seconds by default:

```js
await compare.pipeMicAudio({
  historySeconds: 30,
  packetIntervalMs: 250,
  onPacket: (packet) => console.log("new local packet", packet.timestamp),
});

const localPacket = compare.getLocalPacket();
const result = await compare.compareToSelf(packetFromAnotherDevice);

await compare.stopMicAudio(); // optional; dispose() also stops it
```

`getLocalPacket(timestamp)` returns a copy of the prepared packet whose
timestamp is closest to the requested time, or `null` until the first packet
is ready. `compareToSelf()` uses the remote packet's timestamp to select that
local packet and then calls `compare()`. Both devices must use timestamps from
a sufficiently common clock for nearest-time matching to be meaningful.

Useful options are `historySeconds`, `packetIntervalMs`, additional raw-input
`constraints`, and `onError`. The model window length is read from
`model.json`; callers do not need to duplicate it. `dispose()` stops the
microphone, releases the worker, and clears all pending work.

`AudioComparison` exposes `score`, `label`, `windowScores`, `features`,
`lags`, `quality`, `seconds`, `pairMs`, `deviceMs`, and `totalMs`. Snake-case
aliases are also provided for compatibility with the original demos.
