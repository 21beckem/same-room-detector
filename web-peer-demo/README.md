# Same-room live PeerJS POC

This is a static browser prototype for comparing live microphone audio from two
PeerJS-connected browsers. The page requests microphone capture with echo
cancellation, noise suppression, and automatic gain control disabled, captures
local and remote streams into short in-memory rolling buffers, and performs
WASM scoring in a Web Worker.

The connected view verifies the remote media path before scoring. It checks the
remote track state, the `RTCPeerConnection` ICE/connection state, and inbound
audio RTCP statistics. If signaling succeeds but Wi-Fi, a firewall, or ICE/TURN
prevents media packets from arriving, the page reports that transport failure
and does not label the pair as unrelated. It also reports a separate warning
when packets arrive but the remote microphone is sending near-silence.

The page uses the `peer-code` query parameter for invite links. The displayed
QR code is generated by the QR Server API and contains the complete invite URL.

## Local run

From the repository root:

```powershell
python -m http.server 3000
```

Open `http://localhost:3000/web-peer-demo/`. For two devices, deploy this folder over HTTPS or
use an HTTPS development host; microphone permissions require a secure context
outside localhost.

Live scoring uses `MAX_ALIGNMENT_SECONDS` in `app.js` as the single tuning
value for the allowed WebRTC offset. The model window and minimum input length
are loaded from `model.json`; the page retains the larger of those durations,
plus the allowed alignment history and a one-second capture margin. Audio is
normalized and aligned in the page, then `exports/compare/compare.js` prepares
one compact packet per device and compares only those packets in its worker.
Weak correlations are not used as alignment evidence.
